# Button

The site's button (`.btn`): Cairo 14px/21px weight 500, capitalised, padded 13px × `space-25`, `radius-4`, white text.

- **Primary** (`tk-btn`): `primary` fill; hovers to `ink`.
- **Dark** (`tk-btn tk-btn--dark`): `ink` fill, used for the hero's "Learn More"; hovers to `primary`.
- **Small** (`tk-btn--small`): the header's Arabic language toggle.

The consumer provides the label and link. One primary button per view; pair it with a dark one at most.
