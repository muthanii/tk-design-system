# PartnerStrip

The partner-logo band (`.clients`): logos 102px tall and at most 155px wide, in a row on white, with `space-100` padding above and below. On the site it is a carousel.

The site shows six partners: the Holy Shrine of Imam Hussain, Teebat Karbala, Karbala International Airport, the National Investment Commission, the Iraqi Civil Aviation Authority and ADP. Only the first-party logos are in this system, so the preview shows those two.

The consumer provides each partner's logo file, with real names as `alt` text. The live site uses "#" as `alt`, which should be fixed.
