# Feature

A centred feature column (`.single-features`): a 100px icon circle outlined in `line-strong` with a `primary` icon, then a `feature-title` heading in `ink` and a description in `text`.

On hover the circle fills with `primary` and the icon turns white. In a row (`tk-features`), columns are joined by a 3px dotted `primary` line, the site's signature detail.

The consumer provides the icon, from IcoFont at 50px as on the site: `airplane-alt` for Runway, `building-alt` for Facilities, `ui-network` for connectivity. See the Icons asset group.
